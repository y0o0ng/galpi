# 시온의 원리노트 — 카드뉴스 디자인 v0.2

2026-10-10 사용자 수정 지시를 반영한 시안 기준. 입력 계약의 정본은 README.md, 실행 정본은 render.py다.
최종 목표는 다양한 기술 뉴스를 일관된 미감으로 표현하는 유연한 에디토리얼 템플릿 시스템이다.

## 디자인 목표

도트 그래픽과 미니멀 에디토리얼 방향을 유지하며 독립 기술 매거진의 완성도를 목표로 한다.
아이보리 배경·브랜드 팔레트·도트 제목·산세리프 본문·넉넉한 여백·절제된 장식·공통 헤더/푸터를 유지한다.
모든 페이지를 다르게 만들지 않는다. 내용에 맞는 시각적 강약과 반복되는 질서를 함께 쓴다.

## 우선 적용할 기준

1. 제목 위계: 표지는 크고 과감하게, 설명은 작고 단정하게, 숫자·인용·결론은 강조 콘텐츠가 중심이 되게 한다. 의미 있는 줄바꿈으로 기본 한두 줄을 쓴다.
2. 여백: 텍스트와 그림의 위치·크기를 함께 보고 관계를 만든다. 정보가 적으면 채우지 않고, 주인공이 그림인지 텍스트인지 먼저 정한다.
3. 리듬: 대형 제목·비주얼·텍스트·데이터·분할·강조 문장 중 내용에 맞는 구도를 반복·조합한다.
4. 상자 절제: 과한 카드 중첩을 피한다. 핵심 변화는 사용자의 최신 피드백에 따라 테두리를 빼고 번호 배지·아이콘·내용의 열 정렬과 여백으로 묶는다. 중요한 항목만 배경 면을 더한다. 그래프는 수치 위계를 높이고 테두리/트랙의 무게를 낮춘다.
5. 그림: 뉴스마다 다른 도트 그림을 만든다. 메인 일러스트·설명 도식·작은 아이콘을 다른 공간 규칙으로 다룬다. 텍스트 전용 페이지도 허용한다.
6. 메타데이터: 브랜드·분류·페이지 번호는 일관되게, 출처·날짜는 필요할 때만 표시한다. 모바일 크기에서 읽히는지 확인하되 본문보다 강해지지 않게 한다.

## 기존 뉴스 6장에 적용한 방향

| 페이지 | v0.2 방향 |
| --- | --- |
| 표지 | 비대칭 구도, 120px 던파 비트비트체 v2 제목과 자연스러운 두 줄 |
| 사건 개요 | 72px 던파 비트비트체 v2 제목, 그림 위/설명 아래를 기본 예시로 사용 |
| 핵심 변화 | 테두리 없는 열 정렬·딥그린 배지·38px 잉크색 설명, 항목 수에 따른 간격 |
| 데이터 | 44px 잉크색 수치, 각 지표 옆 판단 기준·큰 막대·완화된 배경 트랙 |
| 한계 | 큰 핵심 문장과 산세리프 설명으로 텍스트 전용 구도 |
| 결론 | 60px 던파 비트비트체 v2 제목, 민트/아이보리 두 색의 72px 문장과 릴스 시온 캐릭터 |

제목·큰 숫자·강조·번호 배지는 던파 비트비트체 v2(DNF Bit Bit v2)의 원본 Regular 한 굵기를 쓴다. 공용 렌더러가 실제 출력 크기에서 원본 가로·세로 비율로 1비트 렌더한다. 가로 확장은 이전 Mona 폰트에만 적용했던 규칙이며 던파체에는 적용하지 않는다. 폰트 파일과 획을 변형하거나 인위적으로 굵게 만들지 않는다. 제목 크기는 표지 120px, 설명 72px, 데이터·조용한 제목 60px다.
머릿말은 위아래 선·릴스 별 실루엣의 픽셀 로고·브랜드명·카테고리·진행 칸·페이지 번호로 구성한다. 진행 칸은 번호 왼쪽에 두고 현재 장은 잉크·읽은 장은 보라·남은 장은 테두리로 구분한다. 로고의 41×53px 모서리는 유지하고 민트로 채우며 바깥에만 4단계 도트 그라데이션을 둔다. 분류와 페이지 번호의 오른쪽 끝을 맞추고 둘 다 굵게 쓴다.
바닥말은 왼쪽 짧은 출처·오른쪽 확정 발행일 한 줄이며 별도 출처 줄과 반복 주제는 없앤다. 날짜를 모델이 추정하지 않는다.
결론의 캐릭터는 사람 그림이 아니라 릴스 시온 스프라이트를 그대로 쓴다.
기존 macOS 시안의 본문은 Apple SD Gothic Neo Medium(index 2)과 잉크색으로 무게·대비를 높였다. 서버 본문은 이후 사용자 승인에 따라 Pretendard Medium/Bold를 사용한다. Apple 시스템 폰트는 서버로 복사하지 않으며 Pretendard의 Pi 적용·지면 검증은 아직 완료되지 않았다.
story·closing·stat·quote는 실제 콘텐츠 묶음 위/아래 여백을 42:58로 배분한다. 명시 content·art_box는 그대로 유지한다.
표지 본문은 제목 아래 콘텐츠 시작에 붙인다. 설명 도식·아이콘·비교 큐브의 출력 도트는 4px로 맞추고 화살표도 도트로 그린다.
아이보리에는 옅은 종이 입자와 드문 2~4px 도트를 더한다. 제목 주변과 머릿말·바닥말은 단색으로 유지하고 표지 오른쪽 아래·결론 오른쪽 바깥 여백에만 낮은 대비의 딥그린 도트 패턴을 둔다. 질감은 고정 seed로 생성하며 콘텐츠 아래에서 합성한다. 중앙 배치 계산은 질감을 콘텐츠로 세지 않는다.
9종 페이지 유형은 유지하며 story에 stacked·visual·split·text 구도를 제공한다.
내용에 맞게 설명 단계를 정하고 각 단계는 1~2페이지로 구성한다. 단계와 진행 순서는 고정하지 않으며 장수 맞추기나 과도한 압축을 하지 않는다.

## 통합 제작 채택 후 자유도

2026-10-10 통합 제작을 기본으로 수용했다. 콘텐츠의 구도·슬롯·타이포그래피 크기·그림 비중은 편 전용 코드에서 조정할 수 있다. 헤더/푸터는 필수 값 변경을 제외하고 공용 frame의 형태·크기·좌표를 그대로 유지한다. 사진은 실제 대상·현장 이해에 도움이 되면 원본 비율로 사용하며 원URL·사용 조건을 보존한다. 픽셀 도식과 사진은 역할에 따라 혼합하고 반복 장식을 강제하지 않는다. 출처 검토는 사실/문구, 시각 검토는 글자 크기/배치/가독성을 담당한다. 현재 정본은 `../prompts/cards_integrated_trial/README.md`다.
