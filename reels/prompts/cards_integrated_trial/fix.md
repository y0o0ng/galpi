## 최종 응답 JSON — 고정 계약

최종 응답은 아래 JSON 객체만 반환한다. 키를 추가하지 않고, Markdown 제목·코드 펜스·설명을 붙이지 않는다. Codex CLI가 이 JSON 스키마를 강제하고 `response.json` 파일로 저장한다. 이 파일을 별도로 직접 작성하지 않는다.

완료했으면:
```json
{"status":"ok","message":"수정과 자가 검토를 완료했어요. 독립 검토는 아직 받지 않았어요."}
```

완료할 수 없으면:
```json
{"status":"blocked","message":"완료할 수 없는 구체적인 이유를 적어요."}
```

`status`는 정확히 `ok` 또는 `blocked`, `message`는 문자열이다. `ok`는 독립 검토 PASS나 게시 승인이 아니다. `report.md`는 출력 목록·조정 이유·미확인 사항을 적는 설명용 문서이며 서버는 여기서 완료 상태를 읽지 않는다.
