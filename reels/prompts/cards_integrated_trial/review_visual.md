# 카드뉴스 — 독립 시각 검토 {{card_id}}

GPT-6.1 Sol 새 세션이다. 선택 후보 {{candidate_card}}, 작업 {{work_dir}}, 출력 {{images_dir}}, 출처 검토 {{source_review_path}}를 읽고 보고서 {{out_path}}만 쓴다.
`{{repo}}/reels/prompts/review_visual_cards.md`의 실제 전 장 원본/390px 축소본 열기·모바일 가독성·그림 의미·브랜드·규격 기준을 적용한다. 이 흐름의 원고 정본은 manuscript.md와 deck.json이며 공용 템플릿의 슬롯·제목 크기·composition·항목 수는 의무가 아니다. 편 전용 렌더 코드의 조정을 계약 위반으로 판정하지 않는다. 팔레트·원본 비율 던파체·Pretendard·시온 캐릭터는 유지한다. 헤더/푸터는 공용 Renderer.frame과 동일해야 하고 로고·브랜드명·선·좌표·크기·폰트·색·진행 표시 형태의 임의 변경은 MUST다. 카테고리·페이지 번호/전체 장수·날짜·출처 값의 정상 변경은 허용한다.
글자 크기·굵기·줄바꿈·문자와 그림 사이의 위계·실제 모바일 가독성은 이 단계의 책임이다. 템플릿의 예전 크기 값과 다르다는 이유로 실패시키지 않고, 제목이나 숫자가 지나치게 커서 내용을 밀어내는지, 본문이 너무 작거나 그림과 균형이 무너지는지 실제 이미지로 판단한다. 읽기와 정보 전달을 해치는 과도한 크기는 MUST로 구체적으로 지적한다.
사진은 허용된 시각 자료다. 사진을 픽셀로 바꾸거나 모든 그림을 픽셀로 통일하라고 요구하지 않는다. 사진과 픽셀 도식이 콘텐츠 역할에 맞게 쓰였는지, 사진 비율/크롭/해상도와 라벨의 연결이 정확한지, 비슷한 픽셀 그림이 의미 없이 반복되는지 확인한다. 소스의 실제 대상을 잘못 보여주는 사진은 MUST다.
제품 정보와 그림이 내용에 맞게 충분한 공간을 쓰는지, 작은 그림과 벌어진 간격 때문에 설명 장이 비어 보이는지 확인한다. 의미 없는 장식과 문장 반복으로 채우라는 수정은 하지 않는다. 의도적인 표지/결론 여백과 내용 부족은 구분한다. 카드 전체의 흐름·글/그림 관계·대담한 강조와 읽기 쉬운 본문·픽셀 디테일도 확인한다.
문제 ID는 V1부터, MUST/NICE를 구분하고 카드·직접 본 파일·위치·문제·구체적 수정 지시를 남긴다. 출처 검토의 문제를 시각 PASS로 덮지 않는다. 못 본 이미지와 읽을 수 없는 자료는 명시한다. 첫 줄 `MUST n / NICE m`, 둘째 줄 `판정: PASS|NEEDS_FIX|BLOCKED`. 모든 원본/축소본 확인 근거와 경로를 남긴다. 보고서 외 파일은 수정하지 않는다.

각 MUST 항목 제목은 정확히 `### V1 — MUST`, `### V2 — MUST`처럼 쓰고, NICE는 `### N1 — NICE`처럼 별도 번호를 쓴다. 제목 아래에 위치·근거·수정 요청을 적는다. MUST가 없으면 MUST 항목을 만들지 않는다.
