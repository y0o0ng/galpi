# XION Reels 도트 트랙 — Production Contract

설계 정본은 `docs/XION Reels Agent — 설계 v0.2.md`이고, 이 문서는 도트 트랙의 **고정 규격·엔진 동작·API·소리 자산·작업 경계**의 정본이다. 조형 원칙은 `../SKILL.md` Part 1, 연출(무대·카메라·움직임·위계·효과음 사용 정책)은 Part 2가 정본이고 여기서 반복하지 않는다. 프롬프트(`reels/prompts/*.md`)는 규칙을 복제하지 않고 이 문서와 스킬을 가리킨다.

**두 형식:** `narration.ko.json`에 `format_version: 2`가 있으면 **형식 2(애니메이션 중심 4px, 새 제작의 기본)**, 없으면 **형식 1(옛 5px 자막 카드)**다. 아래 `## 형식 2` 절이 새 제작의 정본이고, 그 뒤 `화면`·`엔딩`·`자막 카드`·`시간` 절은 **형식 1(옛 영상 재현용)** 기준이다 — 형식 2는 그 절들의 숫자·자막 규칙을 쓰지 않는다. 기존 영상은 새 규칙을 소급 적용하지 않고 일괄 변환하지 않는다.

**읽는 법:** 규칙마다 이유를 함께 적었다. 이유에 맞게 판단하라. `예:`로 시작하는 것은 예시이지 정답이 아니다. **기술 규격과 엔진 사용법에서는** 사용자가 승인한 앞 편 도트판(`reels/episodes/*_px/`, 프레임은 `reels/media/frames/ep0N_px/`)이 가장 확실한 기준이다 — 글로 된 규격과 승인된 화면이 어긋나 보이면 승인된 화면을 따르고 보고한다. 앞 편의 구도·연출은 기준이 아니다(스킬 Part 1·2).

## 경계

- Manim 트랙(`reels/templates/`·`style.py`·`mascot.py`·최상위 `timeline.py`·`sound.py`·`tts.py`·`render.sh`, `_px`가 아닌 `reels/episodes/*`)은 1~4편 기록으로 **동결**이다. 고치지 않는다.
- **제작 에이전트에게 공용 코드 `reels/px/`는 읽기 전용이다** — Pi에는 git이 없어 밤사이 바뀐 공용 코드가 저장소와 어긋난다. 편에 필요한 새 부품은 편 폴더 안에서 만들고, 여러 편에 쓸 만한 것은 사람이 맥에서 템플릿으로 올린다.
- **앞 편 도트판의 화면·소리는 픽셀 하나도 안 바뀌어야 한다.** 공용 코드를 고치면 새 인자의 기본값이 옛 동작이어야 하고, HEAD 기준 전체 프레임·소리 해시로 확인한다. 사용자가 "다음 편부터"로 정한 엔진 상수 변경만 예외이고, 그때 앞 편은 다시 렌더하지 않는다.

## 형식 2 — 애니메이션 중심 4px (2026-10-17, 새 제작부터)

**판별·호환:** `Episode`가 `format_version`을 읽어 `engine.use_format(1|2)`로 전역(`W·H·SCALE·SAFE_OFFSET`…)을 맞춘다(한 프로세스는 한 편). 버전 표기가 없으면 옛 5px 그대로다 — 옛 영상의 프레임·소리 해시는 기준 커밋과 같고 `px/test_legacy_frames.py`가 지킨다. 형식 2는 **자막 카드·타자기·문장 글자 수 시간 계산을 쓰지 않는다**(`split_cards`·`card_secs`·`CARD_BOX`·`draw_card`는 옛 형식과 엔딩 호환용으로만 남아 있다).

| 항목 | 형식 1(옛) | 형식 2 |
| --- | --- | --- |
| 도트 하나의 출력 크기 | 5×5px | **4×4px** |
| 장면 캔버스 / 확장 캔버스 | 180×320 / 216×384 | **225×400 / 270×480** |
| 장면 오프셋 | (12, 40) | **(15, 50)** |
| 출력 · 장면 물리 위치 · FPS | 1080×1920 · x 60~960, y 200~1800 · 24 | **같다** |
| 일반 대상 애니메이션 | 12fps | **12fps** |

- 출력은 정확히 4배 최근접이고 주사선은 각 도트 줄의 마지막 출력 줄이다(출력 lint는 4×4 블록 균일). 오프셋이 4의 배수가 아니어도 배경 Bayer 디더를 장면 좌표로 계산하므로 장면 안팎 이음매가 없다(`test_format2.py`가 확인). 카메라 이동은 출력 24fps 매 프레임 정수 도트, 확대는 최근접 정수배·컷으로 바꾼다(Part 2 §2 그대로).
- **마스코트는 도트 수를 그대로 둔다** — 같은 스프라이트가 물리적으로 20% 작아진다(사용자 결정; 비정수 확대·재작화·5px 혼합 없음). 다른 공용 부품(HUD·UI)은 도트 수를 키워 맞춘다.

### 글자 — `E.say` 하나만 거친다

| 용도 | 폰트 | 출력 | `kind` |
| --- | --- | --- | --- |
| 진술(설명 문구) | `Galmuri14` | 56px | `statement` |
| 라벨 | `Galmuri11` | 48px | `label` |
| 큰 수치·훅 제목 | `Galmuri11-Bold` 2배 | 96px | `number` |

- 비트맵 폰트는 고유 크기에서만 쓴다(리샘플 금지). **모든 장면 글자는 `engine.say`(장면 안에서는 `T.say(img, t, 문구, …)`)로만 그린다.** 형식 2 편에서 `E.text`를 직접 부르면 `RuntimeError`다(엔딩·HUD는 승인 대조를 거쳐 내부에서 부른다).
- **승인 문구 대조:** `say`는 그리는 문자열이 그 편의 승인된 화면 문구(`narration.ko.json`의 장면별 `screen_text`·`labels` 합집합과 훅 줄)에 있는지 본다 — 없으면 `ValueError`(승인되지 않은 사실 주장 금지). 렌더가 끝났을 때 **`screen_text`(진술·수치)나 훅 줄 중 한 번도 안 그려진 것이 있으면 실패**하고 mp4를 지운다(필요한 문구 누락). **`labels`는 선택 승인이라 안 그려도 실패하지 않는다** — 잘 그린 그림은 이름표 없이 읽히므로 라벨은 기본으로 쓰지 않는다. `T.say`는 타임라인에 그 문구의 표시 구간이 있어야 하고(없으면 `ValueError`), 구간 밖에서는 아무것도 안 그린다.
- 기본 문법(이유가 있으면 예외 허용): **진술**은 화면 위 기본 진술 자리(`STMT_Y=14`, 줄 간격 18, 안전 영역 안)에 가운데 정렬, **최대 두 줄**, 즉시 등장·타자기 없음. **라벨**은 가리키는 대상 옆(`xy`, 한 줄). **수치**는 강조색(`INK` 기본) 큰 수치, 대상 근처 또는 진술 자리 아래(기본 y 56). 두 줄을 넘거나 글자 안전 영역 `TEXT_SAFE=(10,12,214,372)`(플랫폼 UI가 위 ~240px·아래 y 1710px~·오른쪽 x 920px~를 가린다) 밖으로 나가면 `ValueError`.
- 한국어가 기본이다. 영어는 고유 기술 용어·국제 약어·단위·원어 표기가 이해를 돕는 경우에만. 텍스트를 줄이려고 정확성을 희생하지 않는다.
- HUD는 `templates.hud`이고 형식 2에서는 **진술 자리와 겹치지 않는 하단 띠** `(10,338)~(214,372)`에 둔다(label 12px·bold 12px). 이름·값도 승인 문구여야 한다. 쓰는 규칙(사실 확인이 받치는 값이 실제 바뀌는 장면에만)은 그대로이고, 영상 전체를 끄는 척추 변수를 만들지 않는다. 형식 1 전용 부품(`hook`·`band`·`steps`·`compare`·`kicker`·`chip`)은 글자를 직접 그리므로 형식 2에서 막힌다. 형식 2의 훅은 아래 `hook2`다.

### 데이터 계약 (fail-close, 렌더 전 `templates.load_v2`가 검증)

`narration.ko.json`(내용 정본; 음성·자막 전문이 아니다):
```json
{"format_version": 2, "hook": "훅 질문", "hook_words": ["질문을", "끊은 1~4줄"], "hook_sub": "선택 부제",
 "scenes": {"장면id": {"content": "전달할 사실·인과", "screen_text": ["반드시 그릴 진술·수치", "..."], "labels": ["선택 라벨"],
                       "evidence": ["사실 확인 행"], "constraint": "보여줘야 할 인과 방향·잘못 그리면 안 되는 것"}},
 "palette": [{"color": "#RRGGBB", "role": "환경|물체·재질|구조·연결부|정보 비교|핵심 변화|강조|발광"}],
 "principle": ["줄1", "줄2", "줄3"], "principle_label": "ENGLISH LABEL", "bgm": "bright|calm|tense"}
```
`scenes.json`(제작 타임라인, 목록): `{"id", "duration"(초, 실제 장면 길이), "events": {이름: 장면 시각}, "texts": [{"text", "start", "end"}]}`. 장면 길이는 글자 수가 아니라 `duration`이다 — 시작 상태 인지, 원인·변화 진행, 결과 확인, 문구 읽기, 연결 시간을 제작이 정한다. `min` 키는 구버전과 혼동하므로 실패다. 검사: 장면 id 집합·순서가 대본과 같음 · `duration` 양수 · `events` 시각이 0~duration · `texts`의 문구가 그 장면 `screen_text`나 `labels`에 있고 · `labels`는 (있으면) 비지 않은 문자열 목록이고 0 ≤ start < end ≤ duration · 엔딩 포함 총 90초 이하 · `hook_words`(비지 않은 문자열 1~4줄; 공백으로 이으면 `hook`과 같다; 줄마다 bold 2배 폭이 `TEXT_SAFE` 안, 한글 8자)·선택 `hook_sub`(라벨 폭 안) · 첫 장면 `duration` ≥ `HOOK_END`(3.9초) · 효과음 시각이 장면 안(`T.sfx = [(T.events["이름"], 종류, 역할)]`로 사건 시각과 맞춘다). 엔딩은 `principle`이 있을 때 자동으로 붙는다(4.2초 그대로).

### 확장 팔레트 — 대표색 기준 역할별 범위

브랜드 대표색(`INK`·`DEEP`·`BG`·`PURPLE`·`TEXT`)·마스코트(`SPRITE_COLORS`)·`PEOPLE_COLORS`·`FIRE_COLORS`·`DANGER`는 값이 안 바뀌고 **범위 검사에서 제외**다. 그 밖의 색(갈색·청회·올리브·물 파랑·적갈 등)은 편이 **`palette`에 색값과 역할로 선언**해야 쓸 수 있다(역할 없는 선언은 실패). 기준값은 현재 `engine.py` 색의 OKLCH다 — BG L 0.180 C 0.031 · DITHER 0.286 / 0.083 · DEEP 0.482 / 0.071 · INK 0.849 / 0.106 · PURPLE 0.678 / 0.187 · DANGER 0.676 / 0.213 · TEXT 0.958 / 0.012.

| 역할 | 명도 L | 채도 C 상한 |
| --- | --- | --- |
| 환경(배경·하늘·지면·원경) | 0.18 ~ 0.60 | 0.083 |
| 물체·재질 / 구조·연결부 | 0.18 ~ 0.958 | 0.106 |
| 정보 비교 / 핵심 변화 / 강조 | 0.18 ~ 0.958 | 0.187 |
| 발광(빛나는 물질: 마그마·용암·필라멘트·번개 등) | 0.18 ~ 0.958 | 0.20 |

공통: 모든 확장색은 L 0.180~0.958. DANGER(C 0.213)보다 채도가 높은 확장색은 없다. DANGER 색상각(h 20°) ±25° 안의 확장색은 C 0.15 이하(발광 제외). **발광색은 프레임마다 캔버스 면적의 15% 이하**(`GLOW_MAX_SHARE`, 렌더 lint) — 빛은 일부에만 쓴다. 환경색 L 상한 0.60 때문에 밝은 배경은 쓰지 않는다. 범위 숫자는 `engine.py`의 `ROLE_RANGES` 한 곳에만 있고 이 표와 같다. **선언 시점**(Episode 생성)에 범위를 벗어나면 렌더 전에 실패하고 메시지에 색값·역할·L·C·위반 경계가 나온다. **렌더 시점**에는 공용 팔레트 + 그 편이 선언한 색 밖의 색이 프레임에 나오면 lint 실패다(다른 편의 선언은 자동 허용되지 않는다; 개수 상한 없음). 같은 물체는 장면 사이에 이유 없이 색을 바꾸지 않고 같은 정보 의미는 같은 색이며 색만으로 필수 정보를 구분하지 않는다(형태·라벨 병행). **범위 통과는 미적 승인이 아니다** — 대비·위계는 시각 검토가 본다. 범위는 초기값이고 조정은 시험 렌더를 보고 사람이 정한다.

### 훅(형식 2) — `templates.hook2`

옛 `hook`의 구성·타이밍·소리를 형식 2로 되살린 첫 장면 템플릿이다(큰 글자는 영문 제목이 아니라 한국어 질문). `hook2(img, d, t, ta, T, nar, art, extra_sfx=())`:
- **큰 글자:** `nar["hook_words"]`가 `T_BIG`(0.3초)부터 0.3초 간격으로 한 줄씩 즉시 뜬다(타자기 없음). `number`(`Galmuri11-Bold` 2배, 96px)·가운데·첫 줄 y 14·줄 간격 28(한 줄 24도트). 줄 수 1~4. `hook_sub`는 마지막 줄 아래 `label` 한 줄.
- **그림:** 마지막 줄 0.3초 뒤부터 `art(img, d, t, ta)`가 남은 무대(큰 글자 아래)에 그린다.
- **마스코트:** `T_SPRITE`(2.4초)에 `HOOK_MASCOT`(놀람 → 반짝)이 오른쪽 아래 발밑 (176, 334)에 튀어나온다(안전 영역 안, HUD 띠 y 338 위, 도트 수 그대로). 소리 `pop`(0.3)·`sparkle`(2.4) + `extra_sfx`는 옛 `hook`과 같다.
- **글자 폭:** 한글 한 글자 24도트·공백 10도트·글자 안전 폭 205도트 → **한 줄 한글 8자**(공백 하나가 있어도 8자). 넘으면 `load_v2`가 줄과 폭을 적어 실패시킨다.
- **승인·게이트:** `hook_words` 줄과 `hook_sub`는 승인 문구에 자동으로 들어가 렌더 게이트(한 번도 안 그려지면 실패)의 대상이다. 대신 `hook` 질문 문자열을 장면 `screen_text`에 따로 넣을 필요가 없다(넣으면 안 그려져 실패하거나 같은 질문이 중복된다).
- **길이·커버:** 첫 장면 `duration` ≥ `HOOK_END` = `T_SPRITE` + 마스코트 놀람·반짝 길이 = 3.9초. 커버는 훅 장면 끝 프레임이라 큰 글자·그림·마스코트가 전부 나온 뒤여야 한다. 형식 1(5px) `hook`은 그대로이고 `hook2`는 형식 2 전용이다.

### 엔딩(형식 2)

구성·징글·도장 시각·효과음·마스코트 역할·4.2초·도장 순간 2프레임 흔들림(한 도트 = 4px)은 형식 1과 같다. 같은 4px 격자에서 도트 수를 늘려 비슷한 물리 크기로 맞췄다(`templates.ENDING[2]`): 도장 78×42 도트, 원리 줄은 `Galmuri11-Bold` 2배(96px)·줄 간격 40 도트, 라벨 `Galmuri11` 48px. **한 줄은 bold 2배 폭이 캔버스 폭 225 이내, 한글 9자까지**(공백 없이)다. 형식 1 엔딩은 바이트 단위 그대로다.

### 소리·커버·제작 경계

- 본편의 문장별 자동 타자음은 없다(엔딩 세 줄 타이핑 소리·징글·도장은 그대로). BGM·합성 효과음·`motion`/`event`/`accent` 정책은 그대로이고 효과음 시각은 장면 타임라인(`events`) 기준이다.

## 화면 (형식 1)

- **무대에서 팔레트 쓰임(새 색 없이):** 살아 있는 배경(물결·흐르는 입자)은 배경 가까운 색(`DEEP`·`DITHER`·`CARD`·`LABEL` 중 어두운 쪽). 변하지 않는 구조물·배경은 `DEEP`·`CARD`·`OUTLINE` 쪽에 가장자리 1도트만 밝게. 무대별 바탕 예: 공기는 `BG`, 물은 `DEEP` 면, 몸속 단면은 `CARD` 면에 `DITHER` 결. 언제 무엇을 앞세울지는 Part 2 §2·§3.

## 엔딩 (형식 1)

- **엔딩 "오늘의 원리" 도장 장면(4.2초)은 `Episode`가 마지막 장면 뒤에 자동으로 붙인다 — 편 코드는 그리지 않는다.** `narration.ko.json`의 `principle`(1~3줄)이 있을 때만 붙고, 마지막 장면에서 도장 장면으로는 그냥 컷이다. `principle_label`(영문 라벨, 선택)은 1.5초에 뜬다. 흐름: "오늘의 원리"(라벨) → 원리 줄 타이핑 1.4초(bold 2배, 마지막 줄만 `INK`) → 2.3초 도장(`원리노트 #NN`, 62×34 이중 테두리 `DANGER`, 안은 비움; NN은 출력 이름 `epNN_…`) + 먼지 + 시온 점프 → 0.3초 뒤 반짝 표정. 도장 순간 2프레임은 출력 전체를 한 도트(5px) 흔든다. 자막 카드는 없다.
- **원리 줄 폭:** 각 줄은 bold 2배로 캔버스 폭 180px 안에 들어가야 하고, 넘치면 실행이 멈춘다. 한글 한 글자 24px·공백 10px이라 **한 줄은 한글 7자까지(공백 없이), 공백이 하나면 7자도 178px로 들어가고 8자는 못 쓴다.** 라벨은 `Galmuri9` 10px, 폭 180px 이내.
- **lint:** 장면 캔버스는 팔레트(밖 색이면 실패)·고립 점(보고만 하고 실패시키지 않는다), 출력 배열은 5×5 블록 균일을 프레임마다 검사한다(`compose`가 캔버스 목록과 출력 배열을 돌려준다). 도장 순간 흔들림은 출력 배열에서 만들므로 출력 lint도 통과해야 한다.
- 커버는 엔딩과 무관하다(훅 끝 프레임).
- `python scene.py --out 이름`은 게시된 결과물을 덮지 않고 다른 이름으로 렌더한다(커버도 같은 이름; 도장의 NN은 이름에서 읽으니 `epNN_`로 시작해야 한다).

## 완성도 디테일(엔진이 자동으로 건다)

- **squash/stretch:** 마스코트 뛰기는 발밑 가운데 기준으로 웅크림·뜀·꼭대기·내려옴·착지(가로·세로배 + dy)로 찌그러졌다 펴지고, 등장 애니메이션(`HOOK_MASCOT`·`SPARKLE_MASCOT`)은 맨 앞에 나타나기 pop 6칸(12fps)이 붙는다. 엔딩 도장 점프도 같다. 밀고 들어오는 `pointer`는 pop·뜀이 없다. 확대는 최근접이다.
- **눈 깜빡임:** base·pointing 표정은 2.5~4초 간격(번호 해시로 결정론적)으로 12fps 1칸 눈을 감는다. surprised·sparkle은 안 감는다.
- **효과음 반응:** `place_sfx`가 실제로 남긴 소리에만 반응한다. `danger`는 그 시각부터 2프레임 출력 전체를 ±5px 좌우로 흔들고, `sparkle`은 0.5초 동안 그 프레임의 마스코트 둘레에 십자 반짝이 4개를 12fps로 깜빡인다(마스코트가 없으면 없음).
- **자막 카드:** 영상 전체의 첫 카드만 상자가 3프레임(24fps) 0.6 → 1.08 → 1.0으로 튀어나오고 글자는 그 뒤부터 보인다(타이핑 시각·타자음은 그대로). 타이핑 중에는 마지막 글자 뒤에 INK 블록 커서가 있고, 다 찍힌 뒤에는 0.5초 켜짐/0.5초 꺼짐으로 깜빡이다 카드가 바뀌면 사라진다.
- 마스코트는 `MascotAnim`(`HOOK_MASCOT`·`SPARKLE_MASCOT`·`pointer`)으로 붙일 때만 걸리고, 편 코드가 `sprite()`를 직접 붙이면 squash·깜빡임·반짝이 반응에서 빠진다.

## 자막 카드 (형식 1 전용)

- 하단 고정 대화창 카드(`CARD` 바탕, 1px 잉크 테두리, 네 모서리 한 점 깎기), **최대 두 줄**, `Galmuri11` Regular 12px(출력 60px). 2026-10-10 사용자 결정으로 새 제작부터 적용하며 게시된 영상은 재렌더하지 않는다. 상자 `(10,252)~(170,290)`·내부 폭 148px는 유지하고 위 여백 6px·줄 간격 16px·커서 6×11px로 맞춘다. 한 줄은 공백 없는 한글 최대 12자이며 공백·숫자·영문을 포함한 실제 폭으로 끊는다.
- **한 문장 = 한 화면이 원칙, 한 화면은 공백 빼고 22자 이하**(대본 계약, 설계 5장). 22자는 상한이지 한 카드에 들어간다는 보장은 아니다. 커진 자막의 실제 줄바꿈을 확인하고 넘으면 대본의 ` / `로 뜻 단위를 나눈다. 카드 분할·길이는 현행 `split_cards`·`sentence_secs`가 같은 폰트로 계산한다.
- 실측: 한글 12px·공백 5px·쉼표/마침표 4px. 한글 12자는 144px로 들어가지만 공백 하나를 더하면 149px로 넘친다. 두 줄의 물리적 최대 24자와 대본 상한 22자는 다르다. `길이가 서로 다른 톱니 아홉 개를 계단처럼 붙였죠.`는 공백 제외 21자여도 낱말 경계 때문에 두 카드다. 작가·대본 검토·제작은 `px/secs.py "문장" "문장"`으로 최종 문장을 검사하며, 각 ` / ` 조각이 22자 이하·실제 한 카드인 `PASS`와 종료 코드 0을 요구한다. 도구는 카드 수·줄별 폭·읽기 시간을 함께 출력하고 미충족이면 `NEEDS_SPLIT`·종료 코드 1로 알린다. 한 낱말 자체가 폭을 넘으면 엔진도 실행을 멈춘다.
- 엔진이 나눈다: 대본의 ` / `(뜻 단위 끊기, 화면엔 안 보임)에서 먼저 카드를 나누고, 카드 안에서는 조사·어미 뒤에서 줄 길이가 고르게 끊는다(`BREAK_AFTER`). 한두 마디만 혼자 뜨는 꼬리 카드가 생기면 쉼표 뒤 공백 자리에 ` / `를 넣어 고친다(글자는 그대로).
- 카드 시간은 글자 수 비율로 나누고, 글자는 한 글자씩 찍힌다(`TYPE_CPS = 14`). 다 찍힌 뒤 남는 시간은 멈춰 있는다. **문장 중간에서 끊긴 카드**(끝이 쉼표·마침표가 아님)는 다음 카드에 문장이 이어지므로 그 멈춤을 절반만 둔다(`MID_HOLD = 0.5`, 최소 시간 1.5초도 적용 안 함).

## 시간 (TTS 없음, 형식 1)

- 문장 시간 = 공백 뺀 글자 수 ÷ `READ_CPS`(5, 글자당 0.2초 — 7은 빨랐다), 카드 한 장 최소 `MIN_CARD`(1.5초). 장면 길이 = max(문장 시간 합 + 여백, `scenes.json`의 최소 길이). 계산은 `engine.sentence_secs`.
- 애니메이션은 **12fps로 끊어** 움직이고(도트 느낌) 출력은 24fps. 위치는 정수 픽셀.
- 연출은 문장에 묶는다: `at(T, 문장번호, 비율)`. 대사보다 그림이 먼저 끝나면 안 된다(4편: 크랭크 타격 세 번이 카드가 "세 개"를 말하기 전에 끝나 셀 수 없었다).

## 소리

- **칩튠 BGM + 작은 타자음 + 효과음.** 크기는 BGM > 효과음 ≥ 타자음, 상수는 `audio.py` 한 곳.
- **BGM:** `px/bgm.py`가 합성하는 곡 세 개(전부 사용자가 귀로 확정, 바꾸지 않는다). 대본이 분위기로 고르고 `narration.ko.json`의 `bgm`에 적는다(없으면 `bright`). 같은 칩튠 악기에 템포·진행·리프·아르페지오만 다르고, 체감 크기는 `SONGS[*].level`로 `bright`에 맞춘다. 영상 길이만큼 B·A 구간을 더 돈다.
  - `bright`(기본): 120 BPM, F장조 7화음, 리드 멜로디 없음(타자음과 부딪혔다).
  - `calm`: 100 BPM, F maj9 진행, 리프·클라베 없음. 아르페지오는 부드러운 삼각파 카페풍(스윙·3·5·7·9음·쉼표·반음 접근음), 피아노보다 6dB 작게.
  - `tense`: 120 BPM, D단조, 베이스 8분음 연타 + 리프. **곡의 끝이 있다** — 엔딩 장면 전 마지막 두 마디를 100 BPM까지 늦추고 F장조 화음을 길게 울린 뒤 징글 직전(장면 1.45초)에 끝난다. 그래서 엔딩의 BGM 1 → 0.35 낮춤을 하지 않는다. 계속 흐르는 `bright`·`calm`은 징글 아래로 이어져도 어색하지 않았고, 긴장이 남은 `tense`만 징글·도장과 부딪혔다. 끝 화음을 F장조로 하는 건 징글 F-A-C-F와 F#이 부딪히지 않게다.
- **타자음:** 글자마다 짧은 비프, 공백·문장 부호는 소리 없음.
- **효과음:** 합성 사인파, 낮은 피치, 둥근 엔벌로프(사각·톱니파는 귀를 찔렀다). 예외로 기계음은 사용자가 귀로 고른 파형을 쓴다 — 스위치 `switch_up`/`switch_down`은 삼각파, 기어 `ratchet`은 아주 짧은(12ms) 사각파 째깍. 지금 있는 종류: `pop`·`sparkle`·`danger`·`bubbles`·`ticks`·`ticks_slow`, 그리고 체감 크기를 `pop`에 맞춘 `rise`·`fall`·`click`·`thud`·`zap`·`radiate`·`crack`·`switch_up`·`switch_down`·`ratchet`(설명은 `audio.sfx` docstring). 새 종류는 BGM 위에서 귀로 확인한 뒤 `sfx`에 더한다.
- **효과음 배치 API:** 사용 정책(무엇을 어떤 역할로 쓸지)은 SKILL Part 2 §5가 정본이다. 장면 함수는 `T.sfx`에 `(장면 시각, 종류, 역할)`로 넣는다 — 역할은 `motion`(동작음)·`event`(사건음)·`accent`(강조음)이고 다른 값이면 렌더가 멈춘다. `audio.place_sfx`는 `motion`·`event`를 간격 없이 항상 넣고, `accent`는 앞 `accent`와 `ACCENT_GAP`(2초) 안이면 버린다. 역할 없이 `(시각, 종류)`로 넣은 소리는 옛 규칙대로 역할 없는 소리끼리 `SFX_GAP`(1초) 간격이다 — 템플릿이 스스로 넣는 소리(훅 `pop`·`sparkle`)와 앞 편이 이 경로라 앞 편 소리는 그대로다. `jingle`·`stamp`(`SFX_EXEMPT`)는 항상 들어간다. 렌더 로그 `sfx kept`/`sfx dropped`에 역할이 함께 찍힌다.
- **끝의 소리 서명:** 엔딩 도장 장면에서만 BGM을 1 → 0.35로 선형으로 낮추고(`tense`는 곡이 이미 끝나 있어 낮추지 않는다) 완성 징글 `jingle`(F5-A5-C6-F6, 장면 1.55초)과 도장 쾅 `stamp`(내려가는 저음 + 짧은 노이즈, 2.3초)을 넣는다. 둘은 `place_sfx`의 최소 간격 규칙에서 빠진다(다른 소리에 밀려 사라지면 안 된다). 세 줄 타이핑에는 타자음이 붙는다. 장면 시작 부분에는 아무 소리도 더하지 않는다.

## 연출

무대·카메라·움직임·시각적 위계는 `../SKILL.md` Part 2가 정본이다.

## 마스코트 "시온"

- `px/sprite.py`(`px/ref/sprite_sheet.png`). 갈피 별 마크를 도트로, 볼터치 없음(중성적). 표정: 기본 · 놀람 · 가리키기 · 반짝임. 놀람·반짝임 동작은 템플릿에 있다(`HOOK_MASCOT`, `SPARKLE_MASCOT`). 가리키기는 `pointer`가 화면 밖에서 밀고 들어왔다 나간다. `face`(기본 `left`, 거울상)로 보는 쪽을 고르고 들어오는 쪽은 그 반대편이다. 스프라이트 눈동자 차이가 1~2px라 6~8편 보고서마다 방향이 확신 없는 곳이었다 → **9편부터 `POINT_LEAN` 0.25로 보는 쪽으로 기운다**(행 단위로 밀기만 해 테두리·팔레트가 그대로다. 회전은 도트 테두리가 깨져 버렸다). 사용자가 "다음 편부터"로 정한 변경이라 1~8편은 다시 렌더하지 않는다.
- 사용 판단(언제 쓰는가)은 Part 2 §3. 다음 편 예고 없음.
- 그림 가장자리·카드 테두리와 살짝 겹치는 건 괜찮다. **자막 카드 글자와 화면 라벨은 가리지 않는다.**
- 회전시키지 않는다(계단이 깨진다). 방향이 필요하면 거울상(`flip`)이나 손으로 찍은 프레임.

## 그림

- **주인공을 크게.** 그 장면이 말하는 대상이 바로 눈에 들어와야 한다(1편 첫 시도에서 관절이 너무 작았다). 비교 카드 안의 작은 그림은 2편 수준이 하한.
- **그림은 대본의 제작 제약(물리·논리 조건)을 어기지 않는다.** 방향·순서·무엇이 무엇에 닿는지가 틀리면 아무리 예뻐도 실패다.
- **기어·톱니 수는 디테일 규칙으로 정한다.** 실제 수(예: 200개)를 그대로 그리면 얇은 선이 되어 기어로 안 보인다. 두께 있는 블록 톱니로, 둘레에 들어가는 만큼만 그리고(`draw.gear`가 상한을 지킨다) 실제 수는 숫자 장면에서 말한다. 화면 라벨은 그림 숫자와 맞춘다.
- **명암 팔레트 짝:** 명암을 넣을지·어디에 넣을지는 Part 1 §3④(모든 면 2단 의무 없음)·디테일 상한은 Part 1 §3⑤. 넣을 때는 새 색 없이 팔레트 짝을 쓴다(INK 면 → 하이라이트 TEXT·`#C9F5DA` / 그림자 DEEP, CARD 면 → 하이라이트 LABEL / 그림자 OUTLINE). 하이라이트·그림자 짝은 디테일 선 하나로 센다.
- **디테일 키트 `px/detail.py`**(`d`는 ImageDraw, 좌표는 정수 도트): `shaded(d, box, base, light, dark)` 명암 2단 면 · `seams(d, box, cols, rows, line, light)` 패널 이음선 · `rivets(d, pts, light, dark)` 나사 · `vents(d, box, dark, light, gap)` 통풍구 · `pipe(d, pts, w, base, light, dark)` 파이프+이음매 · `led(d, x, y, t, on, off, period, phase)` 깜빡이는 표시등 · `glint(d, x, y, n, color)` 반사 줄 · `solar_cells(d, box, cols, rows, base, line, light)` 태양전지 격자 · `board(d, box, fill, trace, pin, pins)` 칩 기판 · `fins(d, box, base, light, dark)` 방열판 핀.

- **HUD(선택 템플릿 `templates.hud(img, items, t, changed_at)`):** 자막 상자 바로 위 한 줄(캔버스 y 222~250, x 4~175, CARD 바탕). `items`는 `[(이름, 값)]` 또는 `[(이름, 값, 색)]` 1~3개 — 색이 있으면 값 앞에 `●` 점과 그 색(INK 정상, DANGER 위험). 이름은 label LABEL, 값은 bold. `changed_at`(리스트 또는 `{번호: 시각}`)의 시각부터 0.3초 그 값만 반전한다. 열 폭은 172÷개수(3개면 값은 한글 4자 안팎). **쓰는 규칙:** 실제로 바뀌는 변수가 있는 장면에만, 사실 확인 목록이 받쳐 주는 측정값·기록값을 같은 편에서도 그 변수가 바뀌는 장면에만 쓴다. 사고실험·장식용 상태값에는 쓰지 않고, 한 편에 HUD 장면이 없어도 된다. HUD가 없는 장면은 화면 전체를 쓴다.

- **소주제 위 띠(선택 템플릿 `templates.band(img, text)`):** 하나의 소주제를 장면 2개 이상에 걸쳐 이어서 설명하는 구간에만 쓴다(그 구간 장면마다 같은 글자). 훅·한 장면짜리 포인트·결론·엔딩 도장에는 쓰지 않는다. 캔버스 맨 위 bold 가운데 글자(y 9~21) + 구분선(y=25, x 4~175)이고, **bold 폭 한계는 168px(공백 없는 한글 14자)** — 넘기면 실행이 멈춘다. 띠가 있는 장면의 그림·라벨은 y 27 아래에서 시작하고, 없는 장면은 화면 전체를 쓴다. 구간이 바뀌면 효과 없이 글자만 바뀐다.

## 도트 그리기 규칙 (코드로 강제 — `px/draw.py`, `px/lint.py`)

| 문제 | 규칙 |
| --- | --- |
| 곡선 울퉁불퉁 | 원·타원은 중점 알고리즘(`draw.circle`·`ellipse`) |

| 픽셀 크기 섞임 | 확대는 정수배만(글자 포함) |
| 색 | 팔레트 밖 색 금지 — `lint`가 렌더를 실패시킨다 |
