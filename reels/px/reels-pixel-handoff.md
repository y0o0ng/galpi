# XION Reels 도트(픽셀) 트랙 — handoff

영상은 도트 트랙으로 만든다. 설계 정본은 `docs/XION Reels Agent — 설계 v0.2.md`이고, 이 문서는 **도트 트랙의 화면·시간·소리·그림 규칙의 정본**이다. 프롬프트(`reels/prompts/*.md`)는 규칙을 복제하지 않고 이 문서를 가리킨다.

**읽는 법:** 규칙마다 이유를 함께 적었다. 이유에 맞게 판단하라. `예:`로 시작하는 것은 예시이지 정답이 아니다. **가장 확실한 기준은 사용자가 승인한 앞 편 도트판**(`reels/episodes/*_px/`, 프레임은 `reels/media/frames/ep0N_px/`)이다 — 글로 된 규칙과 승인된 화면이 어긋나 보이면 승인된 화면을 따르고 보고한다.

## 경계

- Manim 트랙(`reels/templates/`·`style.py`·`mascot.py`·최상위 `timeline.py`·`sound.py`·`tts.py`·`render.sh`, `_px`가 아닌 `reels/episodes/*`)은 1~4편 기록으로 **동결**이다. 고치지 않는다.
- **제작 에이전트에게 공용 코드 `reels/px/`는 읽기 전용이다** — Pi에는 git이 없어 밤사이 바뀐 공용 코드가 저장소와 어긋난다. 편에 필요한 새 부품은 편 폴더 안에서 만들고, 여러 편에 쓸 만한 것은 사람이 맥에서 템플릿으로 올린다.
- **앞 편 도트판의 화면·소리는 픽셀 하나도 안 바뀌어야 한다.** 공용 코드를 고치면 새 인자의 기본값이 옛 동작이어야 하고, HEAD 기준 전체 프레임·소리 해시로 확인한다. 사용자가 "다음 편부터"로 정한 엔진 상수 변경만 예외이고, 그때 앞 편은 다시 렌더하지 않는다.

## 화면

- 캔버스 **180×320**, 출력은 장면 캔버스를 확장 캔버스 216×384의 **(12, 40)**에 붙여 최근접 **5배 확대(1080×1920)**한다(장면 (x,y) → 출력 ((12+x)·5, (40+y)·5); `engine.py`의 `SCALE`·`SAFE_OFFSET`). 이유: 인스타 릴스 UI가 위 ~240px(아이콘)·아래 y 1710~(계정 줄)·오른쪽 x≥920(y 1230~1870, 버튼)·양옆 ~50px를 가린다(1편 스크린샷 실측). 바깥 여백은 장면 배경 공식을 장면 좌표로 확장해 이음매가 없다. 장면 코드는 이 배치를 몰라도 되고, 글자·그림은 캔버스 안에서만 그리면 안전 영역에 든다. 안티앨리어싱 없음(모든 그리기는 1비트 마스크 → 팔레트 색).
- 팔레트(시안 C "아케이드"; `reels/px/ref/mock_C2.png`). 색에는 뜻이 있다 — 같은 뜻에 같은 색:

- 폰트: 갈무리(SIL OFL 1.1, `reels/px/fonts/LICENSE-galmuri.txt`, `bash reels/px/fonts/fetch.sh`로 받음 — 저장소에 TTF 없음). 본문 `Galmuri11` 12px, 강조 `Galmuri11-Bold` 12px, 라벨·자막 `Galmuri9` 10px. 영문 큰 제목은 `Galmuri11-Bold` 2배(캔버스 180px에 11자까지 들어간다: `SPECULATIVE` 170px). 넘치면 1배 bold.
- 화면 안 그림 글자는 영어·숫자·기호이고, **그 편 대본의 화면 글자 목록에 있는 것만** 쓴다. 한국어는 자막 카드와 훅 제목만. 화살표·연산자는 글자 대신 도트 도형.

## 엔딩

- **엔딩 "오늘의 원리" 도장 장면(4.2초)은 `Episode`가 마지막 장면 뒤에 자동으로 붙인다 — 편 코드는 그리지 않는다.** `narration.ko.json`의 `principle`(1~3줄)이 있을 때만 붙고, 마지막 장면에서 도장 장면으로는 그냥 컷이다. `principle_label`(영문 라벨, 선택)은 1.5초에 뜬다. 흐름: "오늘의 원리"(라벨) → 원리 줄 타이핑 1.4초(bold 2배, 마지막 줄만 `INK`) → 2.3초 도장(`원리노트 #NN`, 62×34 이중 테두리 `DANGER`, 안은 비움; NN은 출력 이름 `epNN_…`) + 먼지 + 시온 점프 → 0.3초 뒤 반짝 표정. 도장 순간 2프레임은 출력 전체를 한 도트(5px) 흔든다. 자막 카드는 없다.
- **원리 줄 폭:** 각 줄은 bold 2배로 캔버스 폭 180px 안에 들어가야 하고, 넘치면 실행이 멈춘다. 한글 한 글자 24px·공백 10px이라 **한 줄은 한글 7자까지(공백 없이), 공백이 하나면 7자도 178px로 들어가고 8자는 못 쓴다.** 라벨은 `Galmuri9` 10px, 폭 180px 이내.
- **lint:** 장면 캔버스는 팔레트·고립 점, 출력 배열은 5×5 블록 균일을 프레임마다 검사한다(`compose`가 캔버스 목록과 출력 배열을 돌려준다). 도장 순간 흔들림은 출력 배열에서 만들므로 출력 lint도 통과해야 한다.
- 커버는 엔딩과 무관하다(훅 끝 프레임).
- `python scene.py --out 이름`은 게시된 결과물을 덮지 않고 다른 이름으로 렌더한다(커버도 같은 이름; 도장의 NN은 이름에서 읽으니 `epNN_`로 시작해야 한다).

## 완성도 디테일(엔진이 자동으로 건다)

- **squash/stretch:** 마스코트 뛰기는 발밑 가운데 기준으로 웅크림·뜀·꼭대기·내려옴·착지(가로·세로배 + dy)로 찌그러졌다 펴지고, 등장 애니메이션(`HOOK_MASCOT`·`SPARKLE_MASCOT`)은 맨 앞에 나타나기 pop 6칸(12fps)이 붙는다. 엔딩 도장 점프도 같다. 밀고 들어오는 `pointer`는 pop·뜀이 없다. 확대는 최근접이다.
- **눈 깜빡임:** base·pointing 표정은 2.5~4초 간격(번호 해시로 결정론적)으로 12fps 1칸 눈을 감는다. surprised·sparkle은 안 감는다.
- **효과음 반응:** `place_sfx`가 실제로 남긴 소리에만 반응한다. `danger`는 그 시각부터 2프레임 출력 전체를 ±5px 좌우로 흔들고, `sparkle`은 0.5초 동안 그 프레임의 마스코트 둘레에 십자 반짝이 4개를 12fps로 깜빡인다(마스코트가 없으면 없음).
- **자막 카드:** 영상 전체의 첫 카드만 상자가 3프레임(24fps) 0.6 → 1.08 → 1.0으로 튀어나오고 글자는 그 뒤부터 보인다(타이핑 시각·타자음은 그대로). 타이핑 중에는 마지막 글자 뒤에 INK 블록 커서가 있고, 다 찍힌 뒤에는 0.5초 켜짐/0.5초 꺼짐으로 깜빡이다 카드가 바뀌면 사라진다.
- 마스코트는 `MascotAnim`(`HOOK_MASCOT`·`SPARKLE_MASCOT`·`pointer`)으로 붙일 때만 걸리고, 편 코드가 `sprite()`를 직접 붙이면 squash·깜빡임·반짝이 반응에서 빠진다.

## 자막 카드

- 하단 고정 대화창 카드(`CARD` 바탕, 1px 잉크 테두리, 네 모서리 한 점 깎기), **최대 두 줄**, `Galmuri9` 10px.
- **한 문장 = 한 화면이 원칙, 한 화면은 공백 빼고 22자 이하**(대본 계약, 설계 5장). 이유: 두 줄을 뜻 단위로 고르게 끊으면 24자부터 안 들어가는 문장이 생겼다.
- 엔진이 나눈다: 대본의 ` / `(뜻 단위 끊기, 화면엔 안 보임)에서 먼저 카드를 나누고, 카드 안에서는 조사·어미 뒤에서 줄 길이가 고르게 끊는다(`BREAK_AFTER`). 한두 마디만 혼자 뜨는 꼬리 카드가 생기면 쉼표 뒤 공백 자리에 ` / `를 넣어 고친다(글자는 그대로).
- 카드 시간은 글자 수 비율로 나누고, 글자는 한 글자씩 찍힌다(`TYPE_CPS = 14`). 다 찍힌 뒤 남는 시간은 멈춰 있는다. **문장 중간에서 끊긴 카드**(끝이 쉼표·마침표가 아님)는 다음 카드에 문장이 이어지므로 그 멈춤을 절반만 둔다(`MID_HOLD = 0.5`, 최소 시간 1.5초도 적용 안 함).

## 시간 (TTS 없음)

- 문장 시간 = 공백 뺀 글자 수 ÷ `READ_CPS`(5, 글자당 0.2초 — 7은 빨랐다), 카드 한 장 최소 `MIN_CARD`(1.5초). 장면 길이 = max(문장 시간 합 + 여백, `scenes.json`의 최소 길이). 계산은 `engine.sentence_secs`.
- 애니메이션은 **12fps로 끊어** 움직이고(도트 느낌) 출력은 24fps. 위치는 정수 픽셀.
- 연출은 문장에 묶는다: `at(T, 문장번호, 비율)`. 대사보다 그림이 먼저 끝나면 안 된다(4편: 크랭크 타격 세 번이 카드가 "세 개"를 말하기 전에 끝나 셀 수 없었다).

## 소리

- **칩튠 BGM + 작은 타자음 + 효과음.** 크기는 BGM > 효과음 ≥ 타자음, 상수는 `audio.py` 한 곳.
- **BGM:** `px/bgm.py`가 합성하는 곡 세 개(전부 사용자가 귀로 확정, 바꾸지 않는다). 대본이 분위기로 고르고 `narration.ko.json`의 `bgm`에 적는다(없으면 `bright`). 같은 칩튠 악기에 템포·진행·리프·아르페지오만 다르고, 체감 크기는 `SONGS[*].level`로 `bright`에 맞춘다. 영상 길이만큼 B·A 구간을 더 돈다.
  - `bright`(기본): 120 BPM, F장조 7화음, 리드 멜로디 없음(타자음과 부딪혔다).
  - `calm`: 100 BPM, F maj9 진행, 리프·클라베 없음. 아르페지오는 부드러운 삼각파 카페풍(스윙·3·5·7·9음·쉼표·반음 접근음), 피아노보다 6dB 작게.
  - `tense`: 120 BPM, D단조, 베이스 8분음 연타 + 리프. **곡의 끝이 있다** — 엔딩 장면 전 마지막 두 마디를 100 BPM까지 늦추고 F장조 화음을 길게 울린 뒤 징글 직전(장면 1.45초)에 끝난다. 그래서 엔딩의 BGM 1 → 0.35 낮춤을 하지 않는다. 계속 흐르는 `bright`·`calm`은 징글 아래로 이어져도 어색하지 않았고, 긴장이 남은 `tense`만 징글·도장과 부딪혔다. 끝 화음을 F장조로 하는 건 징글 F-A-C-F와 F#이 부딪히지 않게다.
- **타자음:** 글자마다 짧은 비프, 공백·문장 부호는 소리 없음.
- **효과음:** 합성 사인파, 낮은 피치, 둥근 엔벌로프(사각·톱니파는 귀를 찔렀다). 예외로 기계음은 사용자가 귀로 고른 파형을 쓴다 — 스위치 `switch_up`/`switch_down`은 삼각파, 기어 `ratchet`은 아주 짧은(12ms) 사각파 째깍. 박자에만 — 장면 첫 그림, 마스코트, 위험, 그리고 대본이 정한 **뜻 있는 소리**(소리가 개념을 들려줄 때, 한 편에 1~2개). **최소 간격 2초**(`place_sfx`가 거른다; 뜻 있는 소리가 걸러지면 다른 소리를 옮긴다). 지금 있는 종류: `pop`·`sparkle`·`danger`·`bubbles`·`ticks`·`ticks_slow`, 그리고 체감 크기를 `pop`에 맞춘 `rise`·`fall`·`click`·`thud`·`zap`·`radiate`·`crack`·`switch_up`·`switch_down`·`ratchet`(설명은 `audio.sfx` docstring). 새 종류는 BGM 위에서 귀로 확인한 뒤 `sfx`에 더한다.
- **끝의 소리 서명:** 엔딩 도장 장면에서만 BGM을 1 → 0.35로 선형으로 낮추고(`tense`는 곡이 이미 끝나 있어 낮추지 않는다) 완성 징글 `jingle`(F5-A5-C6-F6, 장면 1.55초)과 도장 쾅 `stamp`(내려가는 저음 + 짧은 노이즈, 2.3초)을 넣는다. 둘은 `place_sfx`의 최소 간격 규칙에서 빠진다(다른 소리에 밀려 사라지면 안 된다). 세 줄 타이핑에는 타자음이 붙는다. 장면 시작 부분에는 아무 소리도 더하지 않는다.

## 마스코트 "시온"

- `px/sprite.py`(`px/ref/sprite_sheet.png`). 갈피 별 마크를 도트로, 볼터치 없음(중성적). 표정: 기본 · 놀람 · 가리키기 · 반짝임. 놀람·반짝임 동작은 템플릿에 있다(`HOOK_MASCOT`, `SPARKLE_MASCOT`). 가리키기는 `pointer`가 화면 밖에서 밀고 들어왔다 나간다. `face`(기본 `left`, 거울상)로 보는 쪽을 고르고 들어오는 쪽은 그 반대편이다. 스프라이트 눈동자 차이가 1~2px라 6~8편 보고서마다 방향이 확신 없는 곳이었다 → **9편부터 `POINT_LEAN` 0.25로 보는 쪽으로 기운다**(행 단위로 밀기만 해 테두리·팔레트가 그대로다. 회전은 도트 테두리가 깨져 버렸다). 사용자가 "다음 편부터"로 정한 변경이라 1~8편은 다시 렌더하지 않는다.
- **역할이 있을 때만:** 훅(놀람), 핵심 지목(가리키기 — 지목 대상 쪽을 보게), 결론(반짝임). 다음 편 예고 없음.
- 그림 가장자리·카드 테두리와 살짝 겹치는 건 괜찮다. **자막 카드 글자와 화면 라벨은 가리지 않는다.**
- 회전시키지 않는다(계단이 깨진다). 방향이 필요하면 거울상(`flip`)이나 손으로 찍은 프레임.

## 그림

- **주인공을 크게.** 그 장면이 말하는 대상이 바로 눈에 들어와야 한다(1편 첫 시도에서 관절이 너무 작았다). 비교 카드 안의 작은 그림은 2편 수준이 하한.
- **그림은 대본의 제작 제약(물리·논리 조건)을 어기지 않는다.** 방향·순서·무엇이 무엇에 닿는지가 틀리면 아무리 예뻐도 실패다.
- **기어·톱니 수는 디테일 규칙으로 정한다.** 실제 수(예: 200개)를 그대로 그리면 얇은 선이 되어 기어로 안 보인다. 두께 있는 블록 톱니로, 둘레에 들어가는 만큼만 그리고(`draw.gear`가 상한을 지킨다) 실제 수는 숫자 장면에서 말한다. 화면 라벨은 그림 숫자와 맞춘다.
- **말한 변화는 화면에서 일어난다.** 문장이 변화를 말하는데(길어진다·커진다·빨라진다·쌓인다) 그 순간 화면이 가만히 서 있으면, 그림이 실제로 그렇게 움직이게 한다(예: 3편 "높이가 길수록 세져서" → 굴뚝이 늘어나고 흐름이 빨라짐). **집착하지 않는다** — 이미 다른 움직임이 그 뜻을 보여 주고 있으면(예: 1편 기어 단이 계속 늘어나며 "크고 무거워져요") 그대로 두고, 기존 움직임을 해치며 끼워 넣지 않는다.

- **그림 품질 규칙:** 주인공 그림은 캔버스 폭의 80%(144px) 이상, 자막 상자 위 세로 공간(y 0~250)의 대부분을 쓴다. 장면이 바뀌면 구도(전경·확대·단면·비교 등)를 바꾸고, 같은 그림에 부품만 붙이는 장면을 3장면 넘게 이어가지 않는다. 이유: 도형만 키우거나 한 구도를 반복하면 면이 비고 화면이 지루하다.
- **큰 그림의 도트 밀도:** 면마다 명암 2단(밝은 가장자리 1도트 + 반대쪽 그림자 1도트, 넓은 면은 디더 음영)을 넣고, 의미 있는 부품 디테일과 작은 움직임(표시등·흐름·진동 등)을 합쳐 **최소 3개** 둔다. **상한:** 디테일 선과 선 사이는 최소 2도트, 폭 6도트 이하 작은 면에는 디더 음영 없음, 한 부품에 디테일 종류는 최대 2~3개, 폰 화면 크기에서 읽혀야 한다(하이라이트·그림자 짝은 선 하나로 센다). 새 색은 만들지 않고 팔레트 짝을 쓴다(INK 면 → 하이라이트 TEXT·`#C9F5DA` / 그림자 DEEP, CARD 면 → 하이라이트 LABEL / 그림자 OUTLINE).
- **디테일 키트 `px/detail.py`**(`d`는 ImageDraw, 좌표는 정수 도트): `shaded(d, box, base, light, dark)` 명암 2단 면 · `seams(d, box, cols, rows, line, light)` 패널 이음선 · `rivets(d, pts, light, dark)` 나사 · `vents(d, box, dark, light, gap)` 통풍구 · `pipe(d, pts, w, base, light, dark)` 파이프+이음매 · `led(d, x, y, t, on, off, period, phase)` 깜빡이는 표시등 · `glint(d, x, y, n, color)` 반사 줄 · `solar_cells(d, box, cols, rows, base, line, light)` 태양전지 격자 · `board(d, box, fill, trace, pin, pins)` 칩 기판 · `fins(d, box, base, light, dark)` 방열판 핀.

- **HUD(선택 템플릿 `templates.hud(img, items, t, changed_at)`):** 자막 상자 바로 위 한 줄(캔버스 y 222~250, x 4~175, CARD 바탕). `items`는 `[(이름, 값)]` 또는 `[(이름, 값, 색)]` 1~3개 — 색이 있으면 값 앞에 `●` 점과 그 색(INK 정상, DANGER 위험). 이름은 label LABEL, 값은 bold. `changed_at`(리스트 또는 `{번호: 시각}`)의 시각부터 0.3초 그 값만 반전한다. 열 폭은 172÷개수(3개면 값은 한글 4자 안팎). **쓰는 규칙:** 실제로 바뀌는 변수가 있는 장면에만, 사실 확인 목록이 받쳐 주는 측정값·기록값을 같은 편에서도 그 변수가 바뀌는 장면에만 쓴다. 사고실험·장식용 상태값에는 쓰지 않고, 한 편에 HUD 장면이 없어도 된다. HUD가 없는 장면은 화면 전체를 쓴다.

- **소주제 위 띠(선택 템플릿 `templates.band(img, text)`):** 하나의 소주제를 장면 2개 이상에 걸쳐 이어서 설명하는 구간에만 쓴다(그 구간 장면마다 같은 글자). 훅·한 장면짜리 포인트·결론·엔딩 도장에는 쓰지 않는다. 캔버스 맨 위 bold 가운데 글자(y 9~21) + 구분선(y=25, x 4~175)이고, **bold 폭 한계는 168px(공백 없는 한글 14자)** — 넘기면 실행이 멈춘다. 띠가 있는 장면의 그림·라벨은 y 27 아래에서 시작하고, 없는 장면은 화면 전체를 쓴다. 구간이 바뀌면 효과 없이 글자만 바뀐다.

## 도트 그리기 규칙 (코드로 강제 — `px/draw.py`, `px/lint.py`)

| 문제 | 규칙 |
| --- | --- |
| 곡선 울퉁불퉁 | 원·타원은 중점 알고리즘(`draw.circle`·`ellipse`) |
| 선 굵기 들쭉날쭉 | 직선은 0°·45°·90°·1:2·2:1 기울기만(`draw.line`) |
| 회전 지글거림 | 최종 해상도에서 매 프레임 돌리지 않는다 — 크게 그려 돌린 각도 프레임 캐시(`draw.baked`) |
| 디테일 뭉개짐 | 최소 형체 2px, 간격 1px. 톱니 수 상한(둘레 ÷ 4px)을 넘으면 `draw.gear`가 오류 |
| 픽셀 크기 섞임 | 확대는 정수배만(글자 포함) |
| 색 | 팔레트 밖 색 금지 — `lint`가 렌더를 실패시킨다 |

## 툴킷

- `px/engine.py` — 캔버스·팔레트·폰트·자막 카드·시간 계산·인코딩(+lint). 인코딩은 Pi 메모리 때문에 x264 스레드 1개.
- `px/templates.py` — `Episode`(장면 실행기: 시간 계획·프레임·엔딩 도장·소리·렌더), `hook`·`compare`·`steps`·`flow`, `chip`·`kicker`·마스코트 동작. `cardt`(문장 안 k번째 카드 시각)·`blinking`·`dotted_rect`·`cutaway`(단면도 확대, 5·8편에서 올림)·`pointer(face=)`. 새 배치는 처음 필요한 편이 만들고, 두 편 이상에 같은 코드가 생기면 사람이 맥에서 여기로 올린다(5~8편 편 폴더의 옛 복사본은 그대로 둔다).
- `px/figure.py` — **사람은 직접 그리지 않고 이걸 쓴다**(9편 다각형 옆얼굴이 두 번 고쳐도 별로였다). `figure(view="side"|"front", hair, cloth, flip, scheme, blink)` 반신상 150×200 + 앵커(`blink=True`는 감은 눈 — 사람이 화면에 오래 있으면 마스코트처럼 2.5~4초 간격으로 12fps 1칸 감긴다)(옆: `eye`·`brain`·`ear`·`mouth`·`nose`·`throat`·`chest`·`back`, 앞: `eye_l`·`eye_r`·`brain`·`nose`·`mouth`·`throat`·`chest`·`heart`) — 머리 안에 그림을 얹거나 빛·흐름을 눈에 닿게 할 때 앵커에 붙인 위치를 더해 쓴다. `icon("woman"|"man"|"girl"|"boy", hair, cloth, flip, scheme)` 작은 얼굴 20×22 — 여러 사람·비교 카드용, 바닥 줄이 같아 아이가 작게 서고 키울 땐 정수배(2배 이상이 잘 읽힌다). 머리 `black`·`brown`·`gray`, 옷 `blue`·`mustard`·`plum`.
- `px/timeline.py` — `span`·`at`·`step`·`tween`과 감속곡선 `linear`·`ease_out`·`ease_in_out`·`back`·`bounce`.
- `px/detail.py`(디테일 키트)·`px/draw.py`·`px/sprite_anim.py`(스프라이트 재생)·`px/lint.py`·`px/audio.py`·`px/bgm.py`·`px/sprite.py`.
