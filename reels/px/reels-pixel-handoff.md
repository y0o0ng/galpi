# XION Reels 도트(픽셀) 트랙 — handoff

2026-10-03 사용자와 정한 방향. Manim 트랙(`reels/` 공용 모듈, 1~4편)은 그대로 두고, **도트 트랙을 따로** 만든다. 첫 대상은 1편(하모닉 드라이브)이다. 설계 정본은 `docs/XION Reels Agent — 설계 v0.2.md`이고, 이 문서는 도트 트랙만의 규칙이다.

## 경계

- 기존 Manim 1편 파일(`reels/episodes/ep01_harmonic_drive/`)과 공용 모듈(`reels/style.py`·`mascot.py`·`templates/`·`timeline.py`·`sound.py`·`tts.py`·`render.sh`)은 **하나도 수정하지 않는다.**
- 도트 엔진은 `reels/px/`에 새로 만든다. 1편 도트판은 새 폴더 `reels/episodes/ep01_harmonic_drive_px/`에서 작업한다.
- `narration.ko.json`과 `scenes.json`은 1편에서 **복사**해서 쓰고 문장은 바꾸지 않는다.
- 결과 영상은 `reels/media/ep01_px_preview.mp4`.
- **첫 장면(`hook`) 하나만 먼저** 렌더해 프레임을 사람에게 보이고, 확인을 받은 뒤 나머지 장면을 진행한다.

- 화면 안 그림 글자는 영어·숫자·기호(Manim 트랙과 같은 규칙). 한국어는 아래 자막 카드와 훅 제목만.

## 자막 카드

- 캔버스 안에 갈무리로 그리는 **대화창 카드**(바탕 `#221C38`, 1px 잉크 테두리, 네 모서리 한 점 깎기). 하단 고정 위치, **최대 두 줄**.
- **한 문장 = 한 화면이 원칙**(2026-10-03 사용자). 카드 한 장은 두 줄, 줄당 한글 약 14자(안쪽 폭 148px, 카드 글자는 `Galmuri9` 10px — 2026-10-03 12px에서 줄임). 두 줄이 되면 조사·어미 뒤에서, 줄 길이가 고르게 끊는다(`BREAK_AFTER`; 꾸미는 말과 꾸밈받는 말을 가르지 않는다). 대본에 ` / `로 표시한 뜻 단위 끊기에서 먼저 카드를 나누고(화면에는 `/` 안 보임), 그래도 넘치면 쉼표·띄어쓰기에서 끊는다.
- **카드 시간은 글자 수 비율**로 문장 시간을 나눈다. 카드 안에서 글자는 한 글자씩 찍히고(타자 효과), 다 찍힌 뒤 남는 시간은 멈춰 있는다.
- 훅 장면의 역설 한 줄·한국어 부제는 위쪽 제목 영역에 같은 폰트로(시안 참고).

## 시간 (TTS 없음)

- **도트 트랙은 TTS를 쓰지 않는다.** 장면 시간은 읽기 속도로 정한다: 문장 시간 = 글자 수(공백 제외) ÷ `READ_CPS`, `READ_CPS = 5`(글자당 0.2초; 7은 빨랐다), 카드 한 장 최소 `MIN_CARD = 1.5`초. 장면 길이 = max(문장 시간 합 + 여백, `scenes.json`의 최소 길이).
- 애니메이션(기어·캠 회전, 마스코트)은 **12fps로 끊어** 움직이고(도트 느낌), 출력 영상은 24fps(같은 그림을 두 프레임씩). 타자 효과는 프레임 단위.

## 소리

- **TTS 없음. 칩튠 BGM + 작은 타자음 + 효과음.**
- **BGM:** `reels/px/bgm.py`가 코드로 합성하는 16비트 키치 곡(2026-10-03 사용자가 귀로 다듬어 확정). 120 BPM, F장조 7화음 진행, **리드 멜로디 없음** — FM 일렉피아노 컴핑, 삼각파 베이스, 킥·셰이커·클라베 림 위에 키치 아르페지오(12.5% 펄스, C5~A5)와 통통 튀는 2마디 리프(25% 펄스, G5~C6, 음 길이 75%). 곡 구성(인트로·A·B·A·브레이크·B·A·아웃트로)으로 반복 피로를 줄이고, 영상이 길면 B·A를 더 돈다. 트랙마다 저역 통과(귀 피로). 영상 내내 낮게 깔되 **타자음보다 크게.**
  - 시도했다 버린 것: 짧은 사각파 루프(반복적·고음 피로), OpenGameArt CC0 곡들(너무 둥글고 지루), 리드 멜로디(배경음으로는 앞에 나섬).
- **타자음:** 글자가 찍힐 때마다 짧은 비프(공백·문장 부호는 소리 없음, 문장 부호 뒤 잠깐 쉼). **작게.**
- **효과음:** 합성 사인파, 낮은 피치, 둥근 어택·릴리즈(사각·톱니처럼 날카로운 파형은 귀를 찔렀다). 기존 Kenney CC0 파일(`reels/sfx/`)도 쓸 수 있다. 박자에만(장면 첫 그림, 마스코트, 위험, 뜻 있는 소리). **최소 간격 2초**(도트 트랙만; Manim 트랙은 3초 그대로).
- 음량 상수는 한 곳에: 대략 BGM > 효과음 ≥ 타자음, 시작값은 엔진 쪽에서 정하고 보고한다.

## 마스코트 "시온" 도트 스프라이트

- `reels/px/sprite.py` (시안 확정본; `reels/px/ref/sprite_sheet.png`). `public/lib/icons/Xion/xion-mark.svg`의 베지어 경로를 그대로 도트로(오목한 네 갈래, 위 꼬리가 길다), 39×51 + 1px 외곽선, 왼쪽 위 하이라이트·오른쪽 아래 그늘 한 단계.
- **볼터치 없음(중성적).** 얼굴은 가로 갈래 줄보다 2px 위(`FACE_Y`).
- 표정: 기본 · 놀람 · 가리키기 · 반짝임. 가리키기는 지금 눈동자만 옆으로 간다 — 꼬리를 기울인 방향별 프레임이 필요해지면 회전 대신 손으로 찍은 프레임으로 만든다(도트를 돌리면 계단이 깨진다).
- 마스코트는 역할이 있을 때만 나온다(Manim 트랙과 같다). 그림 가장자리와 살짝 겹치는 건 괜찮다(사용자 2026-10-03). **자막 카드의 글자와 화면 라벨만 가리지 않는다.**

## 그림

- 1편의 기구학 **관계**는 Manim판과 같다: 서큘러 스플라인 고정, 웨이브 제너레이터 입력, 플렉스플라인 출력, 안쪽이 바깥보다 **2개 적고**, 캠 한 바퀴에 컵이 **반대 방향으로 2칸**, 플렉스는 캠 장축을 따라 타원으로 휜다. 숫자 장면은 실제 수치 200 ÷ 2 = 100.
- **톱니 수는 도트 디테일 규칙으로 정한다**(2026-10-03: 30/32 얇은 톱니는 기어처럼 안 보였다). 두께 있는 블록 톱니(stack 장면 기어처럼), 둘레에 들어가는 만큼만(예: 16/18). 화면 라벨도 그림 숫자와 맞춘다.

## 도트 그리기 규칙 (코드로 강제한다 — `reels/px/draw.py`, `reels/px/lint.py`)

| 문제 | 규칙 |
| --- | --- |
| 곡선 울퉁불퉁 | 원·타원은 중점 알고리즘으로 직접 찍는다(계단 길이가 고르게, 8방향 대칭). 반지름 8 이하는 손으로 다듬은 표. |
| 선 굵기 들쭉날쭉 | 직선은 깔끔한 기울기만(0°·45°·90°·1:2·2:1)로 맞추고, 1px 선의 L자 겹침 점을 지운다. |
| 회전 지글거림 | 최종 해상도에서 매 프레임 돌리지 않는다. 크게 그려 돌린 뒤 줄여 팔레트로 정리한 각도 프레임을 캐시한다(대칭이면 절반만). |
| 디테일 뭉개짐 | 최소 형체 2px, 간격 1px. 원 둘레의 톱니 수 상한(둘레 ÷ 4px)을 넘으면 그리기 함수가 오류를 낸다. |
| 픽셀 크기 섞임 | 확대는 정수배만. 글자도 갈무리 설계 크기의 정수배만. |
| 움직임 떨림 | 위치는 정수 픽셀로, 12fps 단계로 끊는다. |
| 색 | 팔레트 밖 색 금지 — 출력 전 검사기가 실패시킨다. |

## 시간축과 감속곡선 (`reels/px/timeline.py`)

Pillow에는 없어서 만든다. 장면은 "시각 t → 그 순간 그림" 함수이고, `span`(구간 진행도), `at`(문장 시작에 묶기), `step`(12fps 끊기), `tween`(값 보간)과 감속곡선 `linear`·`ease_out`·`ease_in_out`·`back`(팝)·`bounce`(통통)만 둔다.
