# PR #17 — Candidate Absolute Momentum Signal Study

**물은 것:** `SPY > SMA200`인 개발표본에서, `ABS(126,5) > 0` 후보 안에서 다시 뽑은 RS126 TOP5가 **동일 날짜의** 기존 RS126 TOP5보다 +42 forward excess를 높이는가.

**이 PR은 포트폴리오를 건드리지 않는다.** 사전등록은 결과 전에 커밋했고 (`README.md`) HARD A~E와 binding label을 그때 박았다.

**Phase 2의 역할은 마이너스를 플러스로 만드는 것이 아니다.** `J126 + SMA200`은 이미 노출 일치 격차가 +4.99%다(PR #16). 그래서 묻는 것은 **이미 있는 상대 edge를 키우는가, 반대로 좋은 거래까지 잘라먹는가**다.

### 왜 한 번도 안 걸렸는가 — 구조적 이유

**추정이 아니라 측정이다.** `RS = ABS(자기) − ABS(시장)`이므로

```
ABS(자기) = RS + ABS(시장)
```

이고, `SPY > SMA200`인 날짜에는 **시장의 126일 모멘텀 자체가 대개 양수**다. 그러면 RS 상위 종목은 `RS > 0`과 `ABS(시장) > 0`이 겹쳐 **ABS도 필연적으로 양수**가 된다.

구간을 97일 간격으로 훑어 34개 UP 날짜를 표본으로 재봤다.

|값|결과|
|---|---|
|시장 `ABS(126,5)`가 양수인 UP 날짜|**91.9%** (중앙 +0.0909)|
|TOP5 종목 `ABS`의 최솟값|**+0.1876**|
|TOP5 종목 `ABS`의 5백분위 / 중앙|+0.3540 / +0.5268|
|TOP5 중 `ABS <= 0`인 관측|**0 / 170**|

**TOP5의 ABS가 0에 가까이 간 적조차 없다** — 최솟값이 +0.19다. 그래서 문턱을 0 근처에서 조금 올려도 결과가 달라지지 않는다. **다만 그것을 확인하려고 문턱 사다리를 돌리지 않는다** — 사전등록이 금지한 것이고, 이 표만으로도 `ABS > 0`이 이 구조에서 **구속력이 없는 조건**이라는 것이 드러난다.

**이것은 ABS 자체가 쓸모없다는 뜻이 아니다.** `SPY <= SMA200` 구간이나 RS 상위가 아닌 후보군에서는 걸릴 수 있다. 잰 것은 **이 구조(`J126 + SMA200` + TOP5)** 에서 걸리지 않는다는 것뿐이다.

**ABS candidate intervention은 종료한다.** ABS 문턱 변경 · horizon 변경 · ABS를 ranking weight로 변경 · SMA/price breakout 대안 · "조금만 바꿔서 다시"를 하지 않는다. **사용자 검토 없이 다음 대안을 열지 않는다.**

## 10. Limitations

- **개발 표본이다.** 이 구간은 PR #9~#16에서 반복 사용됐고 OOS 검증이 아니다
- **NDX100은 독립 OOS가 아니다** — `ALL`과 중첩되는 sub-universe다
- **portfolio economics를 재지 않았다** — 이 PR은 신호 층이다
- **중첩 표본이다** — 관측 수를 독립 표본 수로 읽지 않았고 p-value를 만들지 않았다
- 무작위 20시드는 coarse control이고 formal test가 아니다
- **인과를 증명하지 않는다**
