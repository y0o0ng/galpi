# signal-j-study — 형성기간 J가 TOP5 초과수익을 어떻게 바꾸는가 (2026-08-16)

**물은 것:** 같은 skip=5 아래에서 형성기간 J를 바꾸면 극단 상위 TOP5의 미래 초과수익
정보가 어떤 구조를 보이는가.

**포트폴리오 백테스트가 아니고 "최적 J 찾기"도 아니다.** 슬롯·수량·비용·청산·체결을 전부
뺀 신호 층 연구다.

**답부터: 긴 형성기간 쪽에 구조적 우위가 있다.** 사전 해석 규칙의 **CASE 3**이고,
포트폴리오 번역 단계로 보낼 challenger는 **J126 하나**다.

> **이 결과는 out-of-sample이 아니다.** 이 개발 구간은 PR #9·#10·#11에서 이미 반복
> 관찰됐다. **model-selection / development-sample research**로 읽는다. 진짜 경제적
> 검증은 앞으로의 paper·live shadow 데이터의 몫이다.

## 1. 질문 — PR #9 → #10 → #11 → J 연구

- **PR #9**(`runs/signal-rs63/`): RS63,5 극단 상위 TOP5에 미래 초과수익과 연관된 정보가
  관찰됐다. ALL에서는 +42 이후에 분명했고, +84까지 평균이 유지됐지만 비중첩 위상에서는
  부호 뒤집힘도 있었다.
- **PR #10**(`runs/jt-k-lifetime/`): J=63·skip=5 고정, K=42/63/84 비교. 긴 신호 수명이
  포트폴리오 개선으로 번역되지 않았고 K42가 기준선으로 남았다.
- **PR #11**(`runs/jt-slot-capacity/`): 5슬롯 용량이 원인인지 검증했다. 점유는 실재했지만
  풀어도 회복되지 않았고, churn·랭크 집중도 진단도 설명하지 못했다. 그 축을 닫았다.
- **이번**: 포트폴리오 층을 벗어나 신호 층으로 내려간다. PR #9이 고정해 두었던 J를 푼다.

## 2. 설계

### RS 정의 — production 함수를 그대로 쓴다

    RS(J, 5) = log(P_i,t-5 / P_i,t-J) − log(P_SPY,t-5 / P_SPY,t-J)

`backtest.features.relative_strength()`를 J만 바꿔 부른다. J마다 유사 구현을 만들지
않았다. `compute_features`를 J마다 다섯 번 부르면 ATR·SMA·변동성까지 다시 계산하므로,
같은 바 배열에 같은 함수를 적용하는 research helper 하나를 뒀다.

### 사다리는 여기서 끝난다

    JS = (21, 42, 63, 126, 189)   ·   SKIP = 5

**J252는 이번 PR에서 제외했다.** `min_history_sessions`(252) 경계를 같이 건드릴 수 있어
"J만 바꾼 실험"이 흐려진다. 테스트가 사다리를 잠근다.

### 사전 고정한 primary endpoint

    ALL 유니버스 · TOP5 · +42세션 · 유니버스 평균 대비 초과수익

K42가 포트폴리오 기준선으로 살아남아 있어서, 실용적 질문이 "K42가 받아먹을 랭킹 신호를
만들 때 J가 어떤 구조를 보이는가"이기 때문이다. **+42가 가장 높아야 좋은 J라는 뜻이
아니다.** 좌표를 하나 고정하지 않으면 J × 지평 표에서 예쁜 칸을 사후 선택하기 쉬워진다.

### 표본이 J마다 갈리지 않는다

자격 판정(`compute_features` + 가격·유동성)에 J가 들어가지 않아 **eligible universe와
날짜 집합이 J 전부에서 동일하다.** 이력 부족으로 빠진 종목은 **두 유니버스 모두 0건**이다.
갈렸다면 "J 효과"와 "표본 구성 효과"가 섞였을 것이다.

무작위 대조군도 J와 무관하다(`sha256(seed|date|symbol)`). 그래서 **공통 baseline 하나**로
계산해 모든 J를 같은 분포와 견준다.

# Interpretation

**사전 해석 규칙의 CASE 3이다** — longer-J family가 primary와 여러 robustness check에서
구조적으로 우세하다.

측정으로 직접 읽을 수 있는 것:

- **짧은 형성기간(J21·J42)은 ALL에서 신호가 없다.** primary에서 음수이고 무작위 분포
  안이다. 이것은 이번 연구의 가장 깨끗한 결과다.
- **J126은 J63보다 반복적으로 높다.** 두 유니버스, 여섯 지평, common anchor, 연 중앙,
  8개 레짐 중 6개에서 그렇다.
- **긴 J의 위상 안정성이 특히 다르다.** PR #9이 J63에서 지적한 약점(부호가 뒤집히는
  위상)이 **ALL에서** J126·J189는 세 지평 모두 0개다. **위상 표는 primary 유니버스(ALL)만
  내므로 이것을 두 유니버스 공통 사실로 읽지 않는다.**
- **J126은 J63과 다른 종목을 고른다**(겹침 1.62/5). 파라미터 미세조정이 아니라 다른
  signal family로 읽어야 한다.
- **긴 J에는 조건부 약점이 있다.** `RECOVERY/HIGH_VOL`과 2009~2011 회복 국면에서 짧은
  J보다 나쁘다. 평균이 높다고 항상 나은 것이 아니다.

**기준선 보존 규칙을 적용하면 J63을 자동 유지하지 않는다.** 규칙은 "J63이 plateau 안에
있고 다른 J가 반복적·구조적으로 우월하다는 증거가 없다면 유지"였는데, 여기서는 두 조건이
모두 반대다.

**그러나 이것은 신호 층의 결과다.** PR #10·#11이 보여준 것은 신호 층의 우위가 포트폴리오
층으로 자동 번역되지 않는다는 것이었다. **이번 결과로 production J를 바꾸지 않는다.**

# Hypothesis

**아래는 다음 연구에서 검증할 것이고 이번 PR이 측정하지 않았다.**

- 긴 J의 `RECOVERY/HIGH_VOL` 약세는 "급반등 국면에서는 오래된 형성기간이 이미 지나간
